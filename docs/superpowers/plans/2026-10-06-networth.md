# netWorth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local Flask web app that finds networking contacts, drafts personalized cold emails into Outlook, and tracks replies, follow-ups, and job applications.

**Architecture:** One Flask process with server-rendered Jinja pages over a SQLite file. Four focused modules: `db.py` (schema and tracking rules), `ai.py` (template filling and Claude calls), `importers.py` (CSV/Excel in and out), `outlook.py` (Microsoft Graph drafts and sync, plus `mailto:` fallback). `app.py` only wires routes to those modules.

**Tech Stack:** Python 3.12 (Homebrew), Flask, Jinja, sqlite3 (stdlib), `anthropic` SDK (model `claude-opus-5-5`, server-side web search tool `web_search_20260209`), `msal` + `requests` for Graph, `openpyxl`, `python-dotenv`, `pytest`.

**Spec:** `docs/superpowers/specs/2026-10-06-networth-design.md`

## Global Constraints

- Runs on `localhost` only, single user, no authentication.
- Default model `claude-opus-5-5`, overridable with env `CLAUDE_MODEL`.
- The app never sends email. Graph scope is `Mail.ReadWrite` only (MSAL adds `offline_access` itself; never request `Mail.Send`).
- Every AI result is shown for review before anything is saved or sent to Outlook.
- Fixed template text is never altered by AI. Only `[[slot: instruction]]` parts are AI-written.
- Duplicate contact = same whitespace-collapsed, case-insensitive name + same company (or both no company).
- Follow-up due = sent date + `profile.followup_days` (default 5). After 2 sent follow-ups with no reply, the Today page suggests `dead`.
- Manual status changes override automation: sync never moves a contact out of `replied`, `call`, `done`, or `dead`.
- Secrets and data stay out of git: `.env`, `networth.db`, `.token_cache.json`, `uploads/`.
- Deviation from spec §8: Outlook draft body is `Text`, not HTML, so line breaks survive without escaping.

## Review Focus

1. Contact with no email address: the draft is still created (Outlook draft with no recipient, or `mailto:?...`) and the user is warned. Tests in Task 5 (`draft_payload`, `mailto_link`); warning in Task 6 route.
2. Same person typed with different spacing or case ("jane  doe" vs "Jane Doe"): treated as a duplicate and skipped. Test in Task 2.
3. Single-word names, missing titles, unknown `{placeholders}`: no crash; leftovers stay visible and are listed above the draft. Tests in Task 3.
4. Real-world export files (UTF-8 BOM, LinkedIn's notes preamble, PitchBook title rows, blank rows, garbage files): import works or fails with a readable message. Tests in Task 4.
5. Claude wraps JSON in prose or code fences: still parsed; non-JSON is retried once then shown as an error. Test in Task 3.

```python
"""SQLite storage and the contact tracking rules for netWorth."""
import datetime as dt
import sqlite3
from pathlib import Path

DB_PATH = Path(__file__).with_name("networth.db")
STATUSES = ("to_contact", "drafted", "sent", "replied", "call", "done", "dead")
APP_STATUSES = ("planned", "applied", "interview", "offer", "rejected")
SOURCES = ("linkedin_csv", "ai_search", "paste", "import")
# Automation (drafting, sync) may only move contacts that are in one of these states.
OPEN = ("to_contact", "drafted", "sent")

SCHEMA = """
CREATE TABLE IF NOT EXISTS profile (
    id INTEGER PRIMARY KEY CHECK (id = 1),
    name TEXT DEFAULT '', program TEXT DEFAULT '', resume_text TEXT DEFAULT '',
    story TEXT DEFAULT '', target_roles TEXT DEFAULT '', voice_samples TEXT DEFAULT '',
    followup_days INTEGER DEFAULT 5
);
INSERT OR IGNORE INTO profile (id) VALUES (1);
CREATE TABLE IF NOT EXISTS companies (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE COLLATE NOCASE,
    domain TEXT DEFAULT '', priority INTEGER DEFAULT 2, notes TEXT DEFAULT '',
    news TEXT DEFAULT '', news_updated_at TEXT
);
CREATE TABLE IF NOT EXISTS contacts (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    company_id INTEGER REFERENCES companies(id),
    title TEXT DEFAULT '', email TEXT DEFAULT '', linkedin_url TEXT DEFAULT '',
    source TEXT NOT NULL CHECK (source IN ('linkedin_csv', 'ai_search', 'paste', 'import')),
    how_connected TEXT DEFAULT '',
    status TEXT NOT NULL DEFAULT 'to_contact'
        CHECK (status IN ('to_contact', 'drafted', 'sent', 'replied', 'call', 'done', 'dead')),
    notes TEXT DEFAULT '', next_followup_date TEXT, followup_count INTEGER DEFAULT 0,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP
);
CREATE TABLE IF NOT EXISTS email_templates (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    kind TEXT NOT NULL CHECK (kind IN ('initial', 'followup')),
    subject TEXT NOT NULL, body TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS messages (
    id INTEGER PRIMARY KEY,
    contact_id INTEGER NOT NULL REFERENCES contacts(id) ON DELETE CASCADE,
    kind TEXT NOT NULL CHECK (kind IN ('initial', 'followup')),
    subject TEXT, body TEXT,
    outlook_message_id TEXT, outlook_conversation_id TEXT,
    created_at TEXT DEFAULT CURRENT_TIMESTAMP, sent_at TEXT, replied_at TEXT
);
CREATE TABLE IF NOT EXISTS applications (
    id INTEGER PRIMARY KEY,
    company_id INTEGER NOT NULL REFERENCES companies(id),
    role TEXT NOT NULL, url TEXT DEFAULT '',
    status TEXT NOT NULL DEFAULT 'planned'
        CHECK (status IN ('planned', 'applied', 'interview', 'offer', 'rejected')),
    applied_date TEXT,
    referrer_contact_id INTEGER REFERENCES contacts(id) ON DELETE SET NULL,
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
);
CREATE TABLE IF NOT EXISTS column_mappings (signature TEXT PRIMARY KEY, mapping TEXT NOT NULL);
"""

DEFAULT_TEMPLATES = [
    ("Intro: coffee chat", "initial", "Waterloo student interested in {company}",
     "Hi {first_name},\n\n"
     "[[hook: one specific line on why I'm reaching out to this person - shared school, their post, their team's work]]\n\n"
     "I'm a {my_program} student at Waterloo looking at {target_role} roles. "
     "[[why_company: one sentence on why {company}, using company notes and news]]\n\n"
     "Would you be open to a 15-minute chat in the next couple of weeks?\n\n"
     "Best,\n{my_name}"),
    ("Follow-up: gentle nudge", "followup", "Re: Waterloo student interested in {company}",
     "Hi {first_name},\n\n"
     "[[nudge: one or two friendly sentences that add something new - a recent {company} update or a short reason I'm still keen - without guilt-tripping]]\n\n"
     "Happy to work around your schedule if a quick chat is possible.\n\n"
     "Best,\n{my_name}"),
]


def connect(path=DB_PATH):
    con = sqlite3.connect(path)
    con.row_factory = sqlite3.Row
    con.execute("PRAGMA foreign_keys = ON")
    con.executescript(SCHEMA)
    if not con.execute("SELECT 1 FROM email_templates").fetchone():
        con.executemany("INSERT INTO email_templates (name, kind, subject, body) VALUES (?, ?, ?, ?)",
                        DEFAULT_TEMPLATES)
        con.commit()
    return con


def clean_name(name):
    return " ".join((name or "").split())


def get_or_create_company(con, name):
    name = clean_name(name)
    if not name:
        return None
    row = con.execute("SELECT id FROM companies WHERE name = ?", (name,)).fetchone()
    if row:
        return row["id"]
    return con.execute("INSERT INTO companies (name) VALUES (?)", (name,)).lastrowid


CONTACT_FIELDS = ("title", "email", "linkedin_url", "how_connected", "notes")


def add_contact(con, name, source, company="", **fields):
    name = clean_name(name)
    if not name:
        raise ValueError("A contact needs a name.")
    company_id = get_or_create_company(con, company)
    dup = con.execute("SELECT 1 FROM contacts WHERE name = ? COLLATE NOCASE AND company_id IS ?",
                      (name, company_id)).fetchone()
    if dup:
        return None
    values = {k: (fields.get(k) or "").strip() for k in CONTACT_FIELDS}
    cols = ["name", "source", "company_id", *values]
    return con.execute(f"INSERT INTO contacts ({', '.join(cols)}) VALUES ({', '.join('?' * len(cols))})",
                       (name, source, company_id, *values.values())).lastrowid


def update_contact(con, contact_id, form):
    values = [(form.get(k) or "").strip() for k in CONTACT_FIELDS]
    con.execute(f"UPDATE contacts SET name = ?, company_id = ?, {', '.join(k + ' = ?' for k in CONTACT_FIELDS)} "
                "WHERE id = ?",
                (clean_name(form.get("name")), get_or_create_company(con, form.get("company")), *values, contact_id))


def get_contact(con, contact_id):
    return con.execute("SELECT c.*, co.name AS company FROM contacts c "
                       "LEFT JOIN companies co ON co.id = c.company_id WHERE c.id = ?", (contact_id,)).fetchone()


def list_contacts(con, status=None, company_id=None, source=None):
    sql = "SELECT c.*, co.name AS company FROM contacts c LEFT JOIN companies co ON co.id = c.company_id WHERE 1 = 1"
    args = []
    for col, val in (("c.status", status), ("c.company_id", company_id), ("c.source", source)):
        if val:
            sql += f" AND {col} = ?"
            args.append(val)
    return con.execute(sql + " ORDER BY c.created_at DESC, c.id DESC", args).fetchall()


def get_profile(con):
    return dict(con.execute("SELECT * FROM profile WHERE id = 1").fetchone())


def followup_due(con, sent_date):
    days = con.execute("SELECT followup_days FROM profile WHERE id = 1").fetchone()[0]
    return (sent_date + dt.timedelta(days=days)).isoformat()


def set_status(con, contact_id, status, today=None):
    """Manual status change. Only 'sent' keeps a follow-up date; every other status clears it."""
    if status not in STATUSES:
        raise ValueError(f"Unknown status: {status}")
    nxt = followup_due(con, today or dt.date.today()) if status == "sent" else None
    con.execute("UPDATE contacts SET status = ?, next_followup_date = ? WHERE id = ?", (status, nxt, contact_id))


def record_draft(con, contact_id, kind, subject, body, outlook_id=None, conversation_id=None):
    mid = con.execute("INSERT INTO messages (contact_id, kind, subject, body, outlook_message_id, "
                      "outlook_conversation_id) VALUES (?, ?, ?, ?, ?, ?)",
                      (contact_id, kind, subject, body, outlook_id, conversation_id)).lastrowid
    con.execute("UPDATE contacts SET status = 'drafted' WHERE id = ? AND status IN ('to_contact', 'sent')",
                (contact_id,))
    return mid


def mark_sent(con, message_id, sent_at):
    msg = con.execute("SELECT contact_id, kind, sent_at FROM messages WHERE id = ?", (message_id,)).fetchone()
    if msg is None or msg["sent_at"]:
        return
    con.execute("UPDATE messages SET sent_at = ? WHERE id = ?", (sent_at, message_id))
    due = followup_due(con, dt.date.fromisoformat(sent_at[:10]))
    con.execute("UPDATE contacts SET status = 'sent', next_followup_date = ?, followup_count = followup_count + ? "
                f"WHERE id = ? AND status IN {OPEN}",
                (due, 1 if msg["kind"] == "followup" else 0, msg["contact_id"]))


def mark_replied(con, message_id, replied_at):
    msg = con.execute("SELECT contact_id, replied_at FROM messages WHERE id = ?", (message_id,)).fetchone()
    if msg is None or msg["replied_at"]:
        return
    con.execute("UPDATE messages SET replied_at = ?, sent_at = COALESCE(sent_at, ?) WHERE id = ?",
                (replied_at, replied_at, message_id))
    con.execute(f"UPDATE contacts SET status = 'replied', next_followup_date = NULL WHERE id = ? AND status IN {OPEN}",
                (msg["contact_id"],))


def add_application(con, company, role, url="", referrer_contact_id=None):
    company_id = get_or_create_company(con, company)
    if company_id is None or not (role or "").strip():
        raise ValueError("An application needs a company and a role.")
    return con.execute("INSERT INTO applications (company_id, role, url, referrer_contact_id) VALUES (?, ?, ?, ?)",
                       (company_id, role.strip(), url, referrer_contact_id)).lastrowid


def update_application(con, app_id, status, referrer_contact_id=None):
    if status not in APP_STATUSES:
        raise ValueError(f"Unknown application status: {status}")
    # Right-hand sides see the old row, so updated_at only moves when the status really changes.
    con.execute("UPDATE applications SET "
                "updated_at = CASE WHEN status != ? THEN CURRENT_TIMESTAMP ELSE updated_at END, "
                "applied_date = CASE WHEN ? = 'applied' AND applied_date IS NULL THEN date('now') ELSE applied_date END, "
                "status = ?, referrer_contact_id = ? WHERE id = ?",
                (status, status, status, referrer_contact_id, app_id))


def today_view(con, today):
    def days_ago(n):
        return (today - dt.timedelta(days=n)).isoformat()

    due = con.execute("SELECT c.*, co.name AS company FROM contacts c LEFT JOIN companies co ON co.id = c.company_id "
                      "WHERE c.status = 'sent' AND c.next_followup_date <= ? ORDER BY c.next_followup_date",
                      (today.isoformat(),)).fetchall()
    unsent = con.execute("SELECT m.id, m.subject, m.created_at, c.id AS contact_id, c.name FROM messages m "
                         "JOIN contacts c ON c.id = m.contact_id "
                         "WHERE m.sent_at IS NULL AND c.status = 'drafted' AND date(m.created_at) <= ? "
                         "ORDER BY m.created_at", (days_ago(2),)).fetchall()
    stale = con.execute("SELECT a.*, co.name AS company FROM applications a JOIN companies co ON co.id = a.company_id "
                        "WHERE a.status IN ('planned', 'applied', 'interview') AND date(a.updated_at) <= ? "
                        "ORDER BY a.updated_at", (days_ago(14),)).fetchall()
    return {"due": due, "unsent": unsent, "stale_apps": stale}
```

```python
SLOT = re.compile(r"\[\[(\w+):\s*(.*?)\]\]", re.S)


class AIError(Exception):
    pass


_client = None


def client():
    global _client
    if _client is None:
        _client = anthropic.Anthropic()
    return _client


# --- template filling (no AI) ---

def fill_data(text, values):
    """Replace {name} placeholders that have a value; leave the rest visible."""
    return PLACEHOLDER.sub(lambda m: str(values[m[1]]) if values.get(m[1]) else m[0], text)


def extract_slots(text):
    return {m[1]: m[2].strip() for m in SLOT.finditer(text)}


def apply_slots(text, filled):
    """Swap each [[slot: ...]] for its AI text; a missing or empty slot stays as a visible marker."""
    return SLOT.sub(lambda m: (filled.get(m[1]) or "").strip() or m[0], text)


def unfilled(text):
    return [m[0] for m in PLACEHOLDER.finditer(text)] + [m[0] for m in SLOT.finditer(text)]


def parse_json(text):
    start, end = text.find("{"), text.rfind("}")
    if start == -1 or end < start:
        raise AIError("Claude did not return JSON.")
    try:
        return json.loads(text[start:end + 1])
    except json.JSONDecodeError as e:
        raise AIError(f"Claude returned invalid JSON: {e}") from e

def _call(system, prompt, search=False):
    messages = [{"role": "user", "content": prompt}]
    extra = {"tools": [WEB_SEARCH]} if search else {}
    for _ in range(5):
        resp = client().beta.messages.create(
            model=MODEL, max_tokens=16000, system=system, messages=messages,
            output_config={"effort": "medium"},
            betas=["server-side-fallback-2026-07-01"], fallbacks="default",
            **extra,
        )
        if resp.stop_reason == "refusal":
            raise AIError("Claude declined this request.")
        if resp.stop_reason != "pause_turn":
            return "".join(b.text for b in resp.content if b.type == "text")
        # Long web search paused mid-turn: send the partial turn back so Claude continues it.
        messages = [messages[0], {"role": "assistant", "content": resp.content}]
    raise AIError("Web search did not finish. Try a narrower search.")


def ask_json(system, prompt, search=False):
    """Ask Claude for a JSON object; retry once if the reply is not valid JSON."""
    for attempt in (1, 2):
        try:
            return parse_json(_call(system, prompt, search))
        except AIError:
            if attempt == 2:
                raise

def fill_slots(slots, context, voice_samples):
    spec = "\n".join(f'- "{k}": {v}' for k, v in slots.items())
    data = ask_json(SLOT_SYSTEM, f"""{context}

<voice_samples>
{voice_samples or '(none provided: write plainly and warmly)'}
</voice_samples>

Write the text for each slot below. Each slot is dropped into a fixed email template, so write only the slot text: no greeting, no sign-off.
{spec}

Reply with only a JSON object mapping each slot name to its text.""")
    return {k: str(v) for k, v in data.items()}

    lines = [_me(profile), f"My resume:\n{profile.get('resume_text') or ''}", "",
             f"Contact: {contact.get('name')}, {contact.get('title') or 'title unknown'} at {contact.get('company') or 'unknown company'}",
             f"How we're connected: {contact.get('how_connected') or 'not connected'}",

        lines += [f"Why I'm interested in {company['name']}: {company.get('notes') or 'none'}",
                  f"Recent news:\n{company.get('news') or 'none'}"]
    for m in prior:

    parts = (contact.get("name") or "").split()
    values = {
        "first_name": parts[0] if parts else "",
        "last_name": parts[-1] if len(parts) > 1 else "",
        "company": contact.get("company") or "",
        "title": contact.get("title") or "",
        "my_name": profile.get("name") or "",
        "my_program": profile.get("program") or "",
        "target_role": re.split(r"[,\n]", profile.get("target_roles") or "")[0].strip(),
    }
    subject, body = fill_data(template["subject"], values), fill_data(template["body"], values)
    slots = extract_slots(subject + "\n" + body)
    if slots:
        filled = fill_slots(slots, _context(profile, contact, company, prior), profile.get("voice_samples") or "")
        subject, body = apply_slots(subject, filled), apply_slots(body, filled)
    return subject, body
```

```python
"""LinkedIn and spreadsheet import, Excel export."""
import csv
import io
import json

import openpyxl

import db

FIELDS = ("name", "first_name", "last_name", "company", "title", "email", "linkedin_url", "how_connected", "notes")
LINKEDIN_MAPPING = {"First Name": "first_name", "Last Name": "last_name", "Email Address": "email",
                    "Company": "company", "Position": "title", "URL": "linkedin_url"}


def import_rows(con, rows, mapping, source, how_connected=""):
    report = {"added": 0, "skipped": 0, "failed": []}
    for n, row in enumerate(rows, start=1):
        f = {field: str(row.get(col) or "").strip() for col, field in mapping.items() if field}
        first, last = f.pop("first_name", ""), f.pop("last_name", "")
        name = f.pop("name", "") or f"{first} {last}"
        if not db.clean_name(name):
            report["failed"].append(f"row {n}: missing name")
            continue
        f["how_connected"] = f.get("how_connected") or how_connected
        if db.add_contact(con, name, source, **f) is None:
            report["skipped"] += 1
        else:
            report["added"] += 1
    return report


def import_linkedin(con, data):
    lines = data.decode("utf-8-sig").splitlines()
    start = next((i for i, line in enumerate(lines) if line.startswith("First Name")), None)
    if start is None:
        raise ValueError("This is not a LinkedIn Connections.csv (no 'First Name' header found).")
    return import_rows(con, list(csv.DictReader(lines[start:])), LINKEDIN_MAPPING,
                       "linkedin_csv", "1st-degree LinkedIn connection")


def read_table(filename, data, sheet=None):
    if filename.lower().endswith(".csv"):
        sheets, grid = ["CSV"], list(csv.reader(io.StringIO(data.decode("utf-8-sig"))))
    else:
        try:
            wb = openpyxl.load_workbook(io.BytesIO(data), read_only=True, data_only=True)
        except Exception as e:
            raise ValueError(f"Could not read {filename}. Upload an .xlsx or .csv file.") from e
        sheets = wb.sheetnames
        ws = wb[sheet] if sheet in sheets else wb[sheets[0]]
        grid = [["" if v is None else str(v) for v in r] for r in ws.iter_rows(values_only=True)]
    # Exports such as PitchBook put title rows above the header: take the first row with 2+ filled cells.
    start = next((i for i, r in enumerate(grid) if sum(1 for v in r if v.strip()) >= 2), None)
    if start is None:
        return sheets, [], []
    headers = [h.strip() for h in grid[start]]
    rows = [dict(zip(headers, r)) for r in grid[start + 1:] if any(v.strip() for v in r)]
    return sheets, headers, rows


def _signature(headers):
    return "|".join(h.lower() for h in headers)


def saved_mapping(con, headers):
    row = con.execute("SELECT mapping FROM column_mappings WHERE signature = ?", (_signature(headers),)).fetchone()
    return json.loads(row["mapping"]) if row else {}


def save_mapping(con, headers, mapping):
    con.execute("INSERT OR REPLACE INTO column_mappings (signature, mapping) VALUES (?, ?)",
                (_signature(headers), json.dumps(mapping)))


def export_xlsx(con):
    wb = openpyxl.Workbook()
    wb.remove(wb.active)
    for table in ("contacts", "companies", "messages", "applications", "email_templates", "profile"):
        cur = con.execute(f"SELECT * FROM {table}")
        ws = wb.create_sheet(table)
        ws.append([d[0] for d in cur.description])
        for row in cur:
            ws.append(list(row))
    buf = io.BytesIO()
    wb.save(buf)
    return buf.getvalue()
```

```python
SCOPES = ["Mail.ReadWrite"]  # MSAL adds offline_access itself. Never add Mail.Send.
CACHE_PATH = Path(__file__).with_name(".token_cache.json")
SYNC_EVERY = dt.timedelta(minutes=10)


class OutlookError(Exception):
    pass


class NotConnected(OutlookError):
    pass


_cache = msal.SerializableTokenCache()
if CACHE_PATH.exists():
    _cache.deserialize(CACHE_PATH.read_text())
_app = None
_me = None
_last_sync = None
login_state = {}


def enabled():
    return bool(os.environ.get("MS_CLIENT_ID"))


def _msal():
    global _app
    if _app is None:
        tenant = os.environ.get("MS_TENANT", "organizations")
        _app = msal.PublicClientApplication(os.environ["MS_CLIENT_ID"],
                                            authority=f"https://login.microsoftonline.com/{tenant}",
                                            token_cache=_cache)
    return _app


def _save_cache():
    if _cache.has_state_changed:
        CACHE_PATH.write_text(_cache.serialize())


def is_connected():
    return bool(_msal().get_accounts())


def start_login():
    """Begin device-code login; a background thread waits for the user to finish in the browser."""
    flow = _msal().initiate_device_flow(scopes=SCOPES)
    if "user_code" not in flow:
        raise OutlookError(flow.get("error_description", "Could not start Outlook login."))
    login_state.clear()
    login_state.update(message=flow["message"], done=False, error=None)

    def wait():
        result = _msal().acquire_token_by_device_flow(flow)
        _save_cache()
        login_state.update(done=True, error=None if "access_token" in result else result.get("error_description"))

    threading.Thread(target=wait, daemon=True).start()


def _token():
    accounts = _msal().get_accounts()
    result = _msal().acquire_token_silent(SCOPES, account=accounts[0]) if accounts else None
    _save_cache()
    if not result or "access_token" not in result:
        raise NotConnected("Outlook is not connected.")
    return result["access_token"]


def _graph(method, path, **kwargs):
    r = requests.request(method, GRAPH + path, headers={"Authorization": "Bearer " + _token()}, timeout=30, **kwargs)
    if r.status_code == 401:
        raise NotConnected("Outlook login expired.")
    if not r.ok:
        raise OutlookError(f"Outlook returned {r.status_code}: {r.text[:200]}")
    return r.json()


def draft_payload(to, subject, body):
    return {"subject": subject, "body": {"contentType": "Text", "content": body},
            "toRecipients": [{"emailAddress": {"address": to}}] if to else []}


def create_draft(to, subject, body):
    m = _graph("POST", "/me/messages", json=draft_payload(to, subject, body))
    return m["id"], m["conversationId"]


def mailto_link(to, subject, body):
    return f"mailto:{quote(to or '')}?" + urlencode({"subject": subject, "body": body}, quote_via=quote)

    global _me

        m = _graph("GET", "/me", params={"$select": "mail,userPrincipalName"})
        _me = (m.get("mail") or m["userPrincipalName"]).lower()

    cid = conversation_id.replace("'", "''")

        "$filter": f"conversationId eq '{cid}'",
        "$select": "isDraft,from,sentDateTime,receivedDateTime"})["value"]


def classify(msgs, me, since):
    """Earliest send by me and earliest reply by anyone else, counting only mail at or after `since`."""
    since = since.replace(" ", "T")[:19]

    def sender(m):
        return ((m.get("from") or {}).get("emailAddress") or {}).get("address", "").lower()

    sent = [m["sentDateTime"] for m in msgs
            if not m["isDraft"] and sender(m) == me and m["sentDateTime"][:19] >= since]
    replies = [m["receivedDateTime"] for m in msgs
               if not m["isDraft"] and sender(m) != me and m["receivedDateTime"][:19] >= since]
    return (min(sent) if sent else None), (min(replies) if replies else None)


def sync(con, force=False):
    global _last_sync
    now = dt.datetime.now(dt.timezone.utc)
    if not force and _last_sync and now - _last_sync < SYNC_EVERY:
        return False
    _last_sync = now
    me = _my_address()
    rows = con.execute("SELECT id, outlook_conversation_id, created_at, sent_at FROM messages "
                       "WHERE outlook_conversation_id IS NOT NULL AND replied_at IS NULL").fetchall()
    for row in rows:
        sent_at, replied_at = classify(_conversation(row["outlook_conversation_id"]), me, row["created_at"])
        if sent_at and not row["sent_at"]:
            db.mark_sent(con, row["id"], sent_at)
        if replied_at:
            db.mark_replied(con, row["id"], replied_at)
    return True
```
